# Android Build (Capacitor shell app)

The Android app is a thin **Capacitor 6 remote-URL shell** (`appId com.creatorstudio.app`): it loads the deployed web app inside a system WebView via `server.url`. It ships no business logic, no secrets, and no embedded UI — all product behavior is on the server, so a web deploy updates the app instantly.

## Configuration

| File | Role |
|------|------|
| `capacitor.config.ts` | Source of truth for app identity + server URL (`CREATOR_STUDIO_SERVER_URL`, default `http://10.0.2.2:3000`) |
| `scripts/mobile/configure-capacitor.mjs` | Build-time script: reads env → writes `capacitor.config.json` (gitignored, regenerated every build) → ensures `webDir` exists |
| `scripts/brand/generate-icons.mjs` | Regenerates the full icon/splash set from the brand mark (pure Node, zero dependencies) |
| `android/` | Native project (committed). Generated by `npx cap add android`; owned sync changes land here via `npx cap sync android` |

## App identity & branding

The app carries a complete, generated identity — no placeholder assets:

- **Name:** `AI Creator Studio` (launcher label + activity title, `res/values/strings.xml`; mirrored in `capacitor.config.ts`)
- **Adaptive icon (API 26+):** vector background (`drawable/ic_launcher_background.xml`, navy→violet→magenta gradient) + vector foreground (`drawable-v24/ic_launcher_foreground.xml`, amber lightning bolt + sparks at the 62% safe-zone scale) wired through `mipmap-anydpi-v26/*.xml`
- **Legacy launchers (API 22–25):** PNG `ic_launcher(.png / _round.png)` at mdpi→xxxhdpi (48…192px) and adaptive-layer `ic_launcher_foreground.png` (108…432px), all generated by the brand script with 4× supersampling
- **Splash:** every default `drawable*/splash.png` bucket replaced with the branded gradient + centered mark (17 assets total)
- **Store listing icon:** `branding/play-store-icon-512.png`

To regenerate after a design change: `node scripts/brand/generate-icons.mjs` — it renders every density/splash bucket in one run, so the whole identity stays reproducible in CI.

Cleartext HTTP is allowed only for the emulator loopback default (`10.0.2.2` maps to the host machine's `localhost`). Any `https:` value gets a clean config with no cleartext flag.

## Requirements

- Node 20, npm
- Java **17** (Gradle toolchain)
- Android SDK (platform-tools + an API platform). `ANDROID_HOME`/`ANDROID_SDK_ROOT` must resolve — CI runners ship with the SDK preinstalled.

## Local build

```bash
# web build (the shell needs a build only to keep webDir valid)
npm run build

# write capacitor.config.json from env + sync into android/
npm run cap:sync

# debug APK
cd android && ./gradlew assembleDebug
# → android/app/build/outputs/apk/debug/app-debug.apk
```

One-liner: `npm run android:debug` (build + cap:sync + assembleDebug).

## Pointing an emulator at your dev app

```bash
npm run dev                      # host terminal: web app on :3000
export CREATOR_STUDIO_SERVER_URL=http://10.0.2.2:3000   # optional; it IS the default
npm run cap:sync
# launch in Android Studio: npm run cap:open, or install the APK onto the emulator
```

For a **physical device**, use your LAN address (`http://192.168.x.x:3000`) — still cleartext (flagged on), acceptable for development only.

## Production build

```bash
CREATOR_STUDIO_SERVER_URL=https://studio.yourdomain.com npm run cap:sync
cd android && ./gradlew assembleRelease   # requires signing config; see below
```

- Register `key.properties` + a release keystore (gitignored via `.gitignore`'s `*.keystore` rule) — release signing is intentionally not automated until you own a signing key.
- Always serve over **HTTPS** in production shells; do not set cleartext.

## CI (GitHub Actions)

`.github/workflows/android.yml` — `workflow_dispatch` (run on demand):

1. Node 20 + `npm ci`
2. Java 17 (Temurin)
3. `node scripts/mobile/configure-capacitor.mjs && npx cap sync android` — uses the default emulator URL unless the repository defines a `CREATOR_STUDIO_SERVER_URL` variable/action input for your fixed deployment target
4. `cd android && ./gradlew assembleDebug` (Gradle wrapper; licenses accepted in-job)
5. Upload artifact **`creator-studio-debug-apk`** (retention 14 days)

## Native project ownership

`android/` is committed so CI (and any contributor) can build without running `npx cap add` first. Regenerate only if Capacitor major upgrades land:

```bash
rm -rf android && npm run cap:add && npm run cap:sync
```

Keep `android/app/src/main/assets/capacitor.config.json` out of reviews except as a reproduction of the source config — `cap sync` rewrites it from `capacitor.config.json` on every build.
