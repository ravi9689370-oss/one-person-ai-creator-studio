# Android App (standalone offline-first)

The Android app (`appId com.creatorstudio.app`, name **AI Creator Studio**) is a **standalone, offline-first app**: the complete UI — every page, asset and route — is a dependency-free vanilla ES-module SPA bundled inside the APK. It boots from local assets with **no server dependency**, so a fresh install works instantly and can never white-screen or show "Could not reach server".

The full studio server (Next.js web app) remains the online product; the mobile app optionally **syncs** with it (Settings → Studio server sync).

## Architecture

| Layer | Path | Role |
|------|------|------|
| SPA source | `mobile-app/` | Source of truth: `index.html`, `assets/css/app.css`, `assets/js/*` (store, ui, charts, maya, sync, main) + `assets/js/views/*` (6 views) |
| Built web dir | `www/` | Generated by `scripts/mobile/build-www.mjs` (gitignored) |
| Native project | `android/` | Capacitor 6 project (committed); `cap sync` copies `www/` → `android/app/src/main/assets/public/` (gitignored, regenerated every build) |
| Sync server | `src/middleware.ts`, `src/lib/auth.ts` | Opt-in CORS + cookie policy for mobile sync via `MOBILE_SYNC_ORIGIN` |

Key properties:

- **No runtime server dependency.** All screens render from local data (IndexedDB, with a localStorage fallback on degraded WebViews). First launch seeds a clearly-labeled sample workspace.
- **No white screens.** Every route render is wrapped in an error boundary; unknown routes get a friendly "Page not found" card; boot failures render an actionable error card with a retry.
- **Honest behavior.** Maya is a rule-based **offline** assistant (self-labeled AI, no fake cloud model). Publishing means *you* paste exported packages — the app never fakes a platform post. Revenue entries are a local ledger, labeled owner-verified/unverified by you. Money is stored in cents.
- **Optional server sync.** Ping (health probe), credentials login, pull morning brief, push unsynced scripts — all real HTTP against the studio server, with human-readable failure messages (offline / CORS / bad credentials / HTTP status).

## Configuration

| File | Role |
|------|------|
| `capacitor.config.ts` | App identity + `webDir: "www"`; no `server.url`, no `allowNavigation` (sync is fetch-based) |
| `scripts/mobile/build-www.mjs` | Copies `mobile-app/` → `www/` and injects the sync server URL (`CREATOR_STUDIO_SERVER_URL`, default `http://10.0.2.2:3000`) into `assets/js/sync.js` |
| `scripts/mobile/configure-capacitor.mjs` | Writes `capacitor.config.json` (gitignored) from the TS config |
| `scripts/brand/generate-icons.mjs` | Regenerates the full icon/splash set from the brand mark (pure Node, zero dependencies) |

## App identity & branding

- **Name:** `AI Creator Studio` (launcher label + activity title)
- **Adaptive icon (API 26+):** navy→violet→magenta gradient + amber bolt, legacy PNGs for API 22–25, 17 splash buckets, `branding/play-store-icon-512.png`
- Regenerate with: `node scripts/brand/generate-icons.mjs`

`android:usesCleartextTraffic="true"` (manifest) + `allowMixedContent` exist only so a user *may* point sync at an `http://` dev server; production sync targets are `https:`.

## Requirements

- Node 20, npm
- Java **17** (Gradle toolchain)
- Android SDK (CI runners ship it preinstalled)

## Local build

```bash
npm run mobile:build     # mobile-app/ → www/ (+ server URL injection)
npm run cap:sync         # configure + build www + cap sync android
cd android && ./gradlew assembleDebug
# → android/app/build/outputs/apk/debug/app-debug.apk
```

One-liner: `npm run android:debug`. Verify the built web dir any time with `npm run mobile:verify`.

## How the app boots (no server, no white screens)

1. WebView loads `assets/public/index.html` **from the APK** (branded boot mark while modules load).
2. `main.js` opens IndexedDB (localStorage fallback), seeds the labeled sample workspace on first run, builds the shell (top bar, 5 tabs, Settings gear, online/offline chip) and renders `#/dashboard`.
3. A per-render error boundary + `window`-level guards mean any unexpected failure shows an error card with **Try again** — never a blank screen.
4. Server calls happen **only** when the user configures sync (Settings); results are reported honestly (reachable / unreachable / not signed in / CORS blocked).

## Enabling server sync (optional)

The app reports sync as blocked unless the server opts in:

1. On the studio server set `MOBILE_SYNC_ORIGIN` to the app's origin (e.g. `http://localhost` for a Capacitor Android WebView, or your domain if configured) — comma-separated list allowed. `src/middleware.ts` then serves CORS headers + preflight for `/api/**` from those origins only.
2. With `MOBILE_SYNC_ORIGIN` set, `src/lib/auth.ts` switches next-auth cookies to `SameSite=None; Secure` (`__Secure-`/`__Host-` prefixed) so the cross-origin session cookie survives — **the server must run https** in this mode.
3. In the app: Settings → Studio server sync → enter URL → **Test connection** → **Login & sync** → **Pull morning brief** / **Push unsynced scripts**.

Without step 1 the app stays fully usable offline and sync surfaces the exact reason.

## Pointing sync at a dev server

```bash
npm run dev                                        # studio server on :3000
export CREATOR_STUDIO_SERVER_URL=http://10.0.2.2:3000     # emulator default anyway
export MOBILE_SYNC_ORIGIN=http://localhost                # app WebView origin
npm run cap:sync && cd android && ./gradlew assembleDebug
```

## Production build

```bash
npm run cap:sync
cd android && ./gradlew assembleRelease   # requires signing config; see below
```

- Register `key.properties` + a release keystore (gitignored via the `*.keystore` rule) — release signing is intentionally not automated until you own a signing key. The debug APK (what CI ships) is auto-signed with the debug keystore and installs on any device.

## CI (GitHub Actions)

`.github/workflows/android.yml` — `workflow_dispatch`:

1. Node 20 + `npm ci`
2. Java 17 (Temurin) + SDK licenses
3. **Build & verify `www/`** — every required module checked for existence, entry point referenced, server URL injected
4. `npm run cap:sync`
5. `./gradlew assembleDebug`
6. Upload artifact **`creator-studio-debug-apk`** (retention 14 days)

`ci.yml` additionally runs `npm run mobile:verify` and the vitest suite on every push — including 12 jsdom smoke tests that boot the real SPA and render **every route** (blank-screen regression guard).

## Native project ownership

`android/` is committed so CI can build without `npx cap add`. Regenerate only on Capacitor major upgrades:

```bash
rm -rf android && npm run cap:add && npm run cap:sync
```
